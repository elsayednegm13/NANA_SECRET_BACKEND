# Contact Form Email via Resend

Render Environment Variables required:

```txt
RESEND_API_KEY=your_resend_api_key_starting_with_re_
CONTACT_TO=elsayedmohamed963@gmail.com
```

Optional if you verify your domain in Resend:

```txt
RESEND_FROM=NANA SECRET Website <info@your-domain.com>
```

If you do not verify a domain, keep the default sender: `NANA SECRET Website <onboarding@resend.dev>`.
